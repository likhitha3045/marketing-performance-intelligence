# Power BI Desktop handoff

The CSV sources and DAX measures in this folder are designed to make the dashboard reproducible in Power BI Desktop. A `.pbix` is a binary authored by Power BI Desktop, so it is not generated by this Python project.

## Load the model

1. Open Power BI Desktop and use **Get data → Text/CSV** to import the eight CSV files from `dataset`.
2. In Power Query, set the date columns to **Date**, budgets/spend/revenue/amount to **Fixed decimal number**, and IDs to **Whole number**. Choose **Close & Apply**.
3. Rename or preserve the imported tables as `channels`, `campaigns`, `customers`, `marketing_spend`, `leads`, `conversions`, `products`, and `transactions`.
4. Create a date dimension using the DAX from [measures.dax](./measures.dax). Mark it as the model's date table.
5. Add single-direction, one-to-many relationships:

| One side | Many side | Relationship |
|---|---|---|
| `channels[channel_id]` | `campaigns[channel_id]` | Active |
| `campaigns[campaign_id]` | `marketing_spend[campaign_id]` | Active |
| `campaigns[campaign_id]` | `leads[campaign_id]` | Active |
| `campaigns[campaign_id]` | `conversions[campaign_id]` | Active |
| `customers[customer_id]` | `leads[customer_id]` | Active |
| `customers[customer_id]` | `conversions[customer_id]` | Active |
| `products[product_id]` | `transactions[product_id]` | Active |
| `Date[Date]` | `marketing_spend[activity_date]` | Active |
| `Date[Date]` | `conversions[conversion_date]` | Inactive |
| `Date[Date]` | `leads[lead_date]` | Inactive |

Use the inactive date relationships in revenue/conversion measures with `USERELATIONSHIP`. Do **not** connect `transactions[amount]` as a second revenue fact in the same visual as `conversions[revenue]`; the sample has one transaction per conversion, so summing both doubles revenue.

## Build the report

Create report pages for the eleven dashboard modules, including analyst findings and forecast/trend exploration. Add date, channel, campaign, customer segment, and region slicers. Use the measures in `measures.dax`; format currency as INR and percentages appropriately. Add drill-through from campaign/channel charts to detail, tooltips for CPA/ROAS, and conditional formatting for budget utilization. Treat any Power BI forecast as exploratory and communicate its method and limitations.

Save as `marketing_dashboard.pbix`. To publish, sign in to Power BI Service, select **Publish**, and choose a workspace. Dataset refresh settings depend on where your production data is hosted.
